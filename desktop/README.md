# The Castaway for Windows

Run **The-Castaway-Setup.exe** to install for your Windows account. Open **The Castaway** from the Start menu. Alternatively, extract every file in **The-Castaway-Windows-x64.zip** into one folder and double-click **The Castaway.exe**. Node.js and a browser are not required.

This release targets Windows 11 x64 and a powerful dedicated graphics card. High starts with 1 m coastal wave geometry, 4096 sun shadows and half-resolution ambient occlusion/reflections. Ultra uses 0.5 m coastal geometry, 8192 sun shadows and full-resolution effects. These are display choices; neither changes the physical simulation. Select your discrete GPU for The Castaway in Windows graphics settings if Windows chooses an integrated adapter.

Drag to orbit, right-drag to pan and scroll to zoom. WASD pans; Q/E orbits. F follows Tomas, C finds his camp, O finds the shore and 1 shows the island. J opens the journal, M switches sound, H hides the interface and F11 toggles full screen. Click Tomas, animals, vegetation, installed buildings or water to inspect their actual state. Ctrl+S saves locally. Settings also export a world checkpoint.

The island follows the current UK clock. A simulation worker advances every original physical minute, including minutes missed while the application was closed. Catch-up progress is shown at startup. It uses the same seed, checkpoint, thought feed, fixed steps and equations as the existing world. Online, it checks the canonical checkpoint and thoughts at startup and every 15 minutes. Offline, it continues with its last available thoughts and saves locally. It does not invent thoughts.

Your save is in `%APPDATA%\The Castaway\world.json`, with `world.previous.json` as a recovery copy. View settings live in the application's browser profile. Export world creates a portable checkpoint containing the saved world and thought history. The application saves on close and every five physical minutes. Removing or updating the application retains these files. Browser website saves are separate; the packaged canonical checkpoint supplies the initial desktop state.

Sun, moon, weather, firelight, ocean displacements, plants, construction, animals and sound read the saved simulation. The renderer can be restarted independently. Rendering accuracy is limited by the original reduced physical models and the graphical reconstruction described in [RENDERING.md](RENDERING.md). This is a stylized physical visualization, not a calibrated fluid-dynamics or radiative-transfer instrument.

For development, install Node.js 24 and pnpm 11, then run `pnpm install --frozen-lockfile` in `desktop/` and `pnpm start`. Dependencies are pinned in `pnpm-lock.yaml`. If Electron's binary is missing, run `node node_modules/electron/install.js`. Run `pnpm test` for analytical projections, unchanged-source fingerprints and old-release golden futures. Generate native QA fixtures with `node test/fixtures.js`, then run `pnpm test:native` on a WebGPU Windows PC. Screenshots and measured reports are written under `desktop/dist/qa/`. Run `pnpm test:production` separately for real-clock catch-up, disk persistence and restart. Set `QA_VISIBLE=1` for a meaningful frame-rate measurement; hidden Windows browser windows throttle animation callbacks. See [TESTING.md](https://github.com/TheRealGD2X/castaway/blob/main/desktop/TESTING.md) for release verification.

Build on Windows x64 with `pnpm package`, or `node tools/package.js C:\absolute\release-directory`. This stages a self-contained application and builds an assisted per-user NSIS installer, portable ZIP, application manifest and SHA-256 checksums. No source files, cloud checkpoints or installed saves are modified by packaging. Set `QA_EXE` to a packaged **The Castaway.exe** and run the same native test to check the actual distributable.

The release is unsigned because this project has no Windows publisher certificate. Installer and executable hashes are supplied in `SHA256SUMS.txt`.
